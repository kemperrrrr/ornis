## 1. P1 — SixDof Locked: локальный вектор проецируется на мировую ось

Код:

- primal: [`avbd.rs:2353–2365`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L2353-L2365);
- новый dual: [`avbd.rs:2978–2988`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L2978-L2988);
- контракт: [`joint.rs:133–148`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/joint.rs#L133-L148), оси задаются в системе тела A.

```rust
let qrel = a.orientation.conjugate() * b.orientation;
let diff = quat_diff_vec(qrel, j.q_ref);
let dir = (a.orientation * *e).normalize_or(*e);
let c = diff.dot(dir);
```

`qrel` и `diff` выражают относительное вращение **в локальной системе A**. `dir` уже переведён **в мировую систему**. Скалярное произведение величин из разных базисов не является ошибкой вокруг заданной локальной оси.

### Численный контрпример

В обоих сравниваемых вариантах тела создаются с одинаковой ориентацией, поэтому `q_ref=I`. Затем B получает относительный поворот 0.3 rad вокруг локальной Z тела A:

```text
qA = Ry(φ)
qB = qA · Rz(0.3)
qA⁻¹ qB = Rz(0.3)
```

Ограничена только локальная angular Z, остальные оси свободны. Правильная невязка этой строки одинакова для любого общего поворота φ:

| Общий поворот A, φ | Текущий `C` | Ожидаемый `C` |
|---|---:|---:|
| 0 | 0.300000000 | 0.3 |
| 0.7 rad | 0.229452656 | 0.3 |
| π/2 | ≈0 | 0.3 |

При φ=π/2, `K=1`, `λ=0` строка считается неактивной: и C, и сила попадают ниже `C_EPS`. При этом нарушение locked-оси реально составляет 0.3 rad. Это не только небольшая ошибка точности, а зависимость работы ограничения от ориентации конструкции в мире.

**Важно:** неверный primal был уже до этого коммита. Текущий фикс добавляет соответствующий dual и новый тест, закрепляющий тот же дефект; это не заявление, что ошибка целиком впервые появилась сейчас.

### Новый тест закрепляет неправильное ожидание

[`sixdof_angular_rows_commit_duals_in_local_frame`, строки 50–55](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd_joint_tests.rs#L50-L55) ожидает для locked-строки именно:

```rust
0.3 * 0.7f32.cos()
```

Здесь должно проверяться инвариантное относительное вращение, а не результат смешения координат. Само совпадение primal и dual не доказывает корректность выбранного C.

**Исправление:** использовать локальный `diff.dot(*e)` / `diff[i]`, сохраняя мировой `dir` для применения момента, либо сначала перевести `diff` в мировой базис. Согласованно исправить primal, dual и ожидаемое значение теста.

Предлагаемый unit-тест в существующем `avbd_joint_tests.rs` (не запускался здесь):

```rust
#[test]
fn sixdof_locked_axis_is_invariant_to_world_rotation() {
    for pitch in [0.0, 0.7, std::f32::consts::FRAC_PI_2] {
        let mut e = row_scene(AvbdJointKind::SixDof);
        let qa = Quat::from_rotation_y(pitch);
        e.bodies[0].orientation = qa;
        e.bodies[1].orientation = qa * Quat::from_rotation_z(0.3);
        e.joints[0].six_ang[2] = AxisConfig::Locked;
        e.dual_update();
        assert!((e.joints[0].lam_a[2] - 0.3).abs() < 1e-6);
    }
}
```

## 2. P2 / остаток A4 — Angular gate сравнивает момент с линейным масштабом

Код:

- [`row_live`, строки 615–617](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L615-L617);
- линейный и угловой инерционные блоки: [`1861–1869`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L1861-L1869);
- пример угловой строки Fixed: [`2441–2449`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L2441-L2449).

Применение `row_live` к joints исправило прежние примеры с ненулевой λ при `C=0`. Но в angular-строки передаётся тот же `m_dt2=m/h²`, что и в линейные:

```rust
if !row_live(c, f, j.pen_a[k], m_dt2) {
    continue;
}
```

Для углового движения инерционный масштаб определяется `I/h²`, а не `m/h²`. Две величины имеют разные физические размерности и по-разному масштабируются с размером тела.

### Контрпример удерживающего равновесия

Динамическая сфера массой 1 кг и радиусом 0.01 м. По используемой в проекте формуле `I=0.4·m·r²=4e-5 кг·м²`. При `h=1/60`:

```text
m/h² = 3600
I/h² = 0.144
C = 0
|λ| = 0.0001 Н·м
Kangular = 10000
```

Текущий gate даёт false:

```text
|λ| < K·C_EPS = 0.001
|λ| < (m/h²)·C_EPS = 0.00036
```

Но момент значительно больше углового масштаба `(I/h²)·C_EPS=1.44e-8`.

В нагруженном равновесии можно иметь инерционный gradient `+0.0001` и удерживающую реакцию `−0.0001`. Полная строка даёт шаг ноль. Если удалить и реакцию, и её Hessian, угловой шаг становится:

```text
Δθ = −0.0001 / 0.144 ≈ −0.000694444 rad
```

Это почти 7000 значений `C_EPS`, а не неразрешимая «пыль». Скалярный пример относится к изолированной угловой строке с единичным Jacobian, нулевыми плечами линейных якорей и без контактов.

**Исправление:** оценивать допустимый пропуск angular-строки через угловую инерцию/ожидаемое изменение ориентации, а не через линейную массу. Для произвольных осей и неединичных Jacobian учитывать проекцию инерционного отклика. Не заменять линейный масштаб на угловой во всех строках без разбора.

Нужен дополнительный тест малого момента и малого момента инерции в нагруженном равновесии. Новые тесты с λ=10 подтверждают другой, уже исправленный случай и этот дефект не покрывают.

### A1: теперь один вращательный вклад

[`avbd.rs:1771–1789`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L1771-L1789):

```text
ΔpA = positionA − pos0A
C = (1−α)C₀ + u·(ΔpA−ΔpB) + (rA×u)·ΔθA − (rB×u)·ΔθB
```

Прежний пример `θ=0.001` теперь даёт `0.0009999995000` вместо `0.0019999993333`.

Помимо изменения формулы добавлены per-point глубины контактов, геометрические полюса сфер и согласованные friction-levers. **Положительный момент:** это не только удаление слагаемого с подменой snapshot; появились адресные проверки вращательного члена, сферической нормали, геометрии якорей и качения.

### Gear: angular-only в памяти и в live read

- [`gear_sides:2631–2650`](https://github.com/kemperrrrr/ornis/blob/c97089a9d22ac58ce895d89c75415b3b5abcc01c/crates/physics/src/avbd.rs#L2631-L2650): unwrap выполняется только при `angular`.

Добавлен `avbd_gear_linear_sides_no_wrap_teleport` (`tests/avbd_engine.rs:815–879`): два prismatic-джойнта и реальный 4-метровый host-jump внутри интервала памяти. Он адресует исходный контрпример, а не просто большой суммарный путь за множество малых шагов.

- оба направления нагрузки;

Это содержательное устранение прежней слабости «проверяем только конечную позу, возможно уже спящую». **Успешный локальный прогон этих Rust-тестов не заявляется.**
