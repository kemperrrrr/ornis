## Что видно без полных логов

Прогон `32653318674` (workflow_dispatch, `56c05c5`, ~14ч назад):

- **cargo mutants (ornis-physics)** — упал с exit code 3. Аннотации
  перечисляют пропущенные (missed) мутанты — то есть мутационные тесты
  не покрывают:
  - `crates/physics/src/distance.rs` — `seg_seg_closest` (несколько
    операторных мутаций: `/`→`%`, `<`→`<=`, `<`→`==`, `&&`→`||`,
    строки 50/53/54) и `point_segment_closest` (`<`→`<=`, строка 32);
  - `crates/physics/src/body.rs` — `RigidBody::apply_torque`
    (`+=`→`-=`, строка 92), `RigidBody::set_orientation` (мутант в
    `()` — функция целиком не проверяется, строка 83),
    `RigidBody::build` (`/`→`*`, строка 35).
  - Это классические missed mutants: код синтаксически варьируется, а
    тесты продолжают проходить — сигнал, что покрытие именно этих
    веток геометрии/динамики недостаточно точное (проверяют «не
    паникует», а не численный результат).
- **Miri (ornis-core)** — упал с exit code 1 на шаге `cargo +nightly
  miri test -p ornis-core --lib`. Без полного лога не видно, какой
  тест/UB-репорт — только факт падения. Кандидаты по описанию workflow
  («самые интересные unsafe-блоки»): `lock_free_store`, `prefetch`,
  `smart_store`.
- Более свежий прогон `32687614740` (сегодняшний ночной cron) вообще
  не стартовал: «recent account payments have failed or your spending
  limit needs to be increased» — это биллинг GitHub Actions на уровне
