## Добавленные конфиги

- **`deny.toml`** — advisories (стандарт), bans (`multiple-versions = "warn"`),
  licenses (allow: MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2/3-Clause,
  ISC, Zlib, Unicode-3.0, **+ MPL-2.0, CC0-1.0** — см. отклонения ниже),
  sources (`unknown-registry/git = "deny"`). Path-зависимости (`forks/boa_engine`,
  `[patch.crates-io]`) проверкой sources не затрагиваются.
- **`rustfmt.toml`** — `max_width = 100` (явный дефолт), edition 2024 из Cargo.toml.
- **`[workspace.lints.clippy]`** в корневом `Cargo.toml` — `all = "warn"`.
  pedantic не включён; `unwrap_used`/`expect_used` не подняты (после baseline).
- **`[lints] workspace = true`** — добавлено во все 10 манифестов
  (корень + core, macros, ui, wgpu_backend, audio, render, materialx, wasm, xtask).
- **`license.workspace = true`** — добавлено в 9 манифестов (кроме xtask,
  у которого `publish = false`). Без этого `cargo deny check licenses`
  падал с `unlicensed` на всех крейтах workspace.

### Отклонения от плана (с причинами)

1. **Allow-list лицензий расширен**: реально используются MPL-2.0
   (стек lightningcss/cssparser из Servo — 8 крейтов), CC0-1.0 (option-ext ← dirs),
   NCSA (libfuzzer-sys, через exception). Без них `licenses FAILED`.
2. **Clippy прогонялся без `--all-targets`**: примеры `crates/ui/examples/`
   не компилируются (unresolved imports `anyrender`, `blitz_dom` и др. —
   замороженный экспериментальный стек). Прогон: `--workspace --lib --bins --tests --benches`.
3. **Минимальный фикс для разблокировки прогона**: `crates/wgpu_backend/src/leak.rs:210`
   (тест) — `wgpu::PollType::Wait` → `PollType::Wait { submission_index: None, timeout: None }`
   (API wgpu 29). Файл в числе незакоммиченных правок владельца — правка оставлена
   в дереве, **не закоммичена**.

## Рекомендуемый порядок лечения

1. **Безопасность**: bump `quick-xml` 0.31 → 0.41 в `ornis-materialx`
   (закрывает обе high-уязвимости; проверить совместимость API парсера).
2. **Correctness**: просмотреть `unnecessary_cast` (8) и `unused Result` вручную —
   это единственные линты с потенциальным смысловым эффектом.
3. **Архитектура**: выровнять версии `glam` (0.28 → 0.30+ в macros) и `pollster`;
   решить судьбу unmaintained-стека шрифтов в замороженном ui
   (rustybuzz/ttf-parser → skrifa) — либо при пивоте, либо при удалении.
4. **Стиль (массово, отдельным коммитом)**: `cargo clippy --fix` для
   `collapsible_if` (215) и др. + `cargo fmt` для `xtask/src/main.rs`.
   После зачистки поднять `unwrap_used`/`expect_used` до warn и снять новый baseline.
5. **Покрытие**: прогнать `cargo llvm-cov` и зафиксировать baseline покрытия тестами.
