## Known gaps (not regressions — by design)

- `crates/audio/src/engine.rs` (103 lines, ~90%): `AudioEngine` orchestration
  is covered headless through `MockBackend`. Construction of the real `cpal`
  stream remains device-specific and is not required in CI; mixer tests
  (`pan_sample`, `distance_attenuation`, `mix`) and decoder tests cover the
  platform-independent behavior.
- `crates/macros/src/{kernel,gpu_pipeline,for_each_entity}` error paths:
  the `compile_error!` branches are only exercised by trybuild on `Pack`;
  the other macros' error paths are not yet under compile-fail tests.
- `ornis-materialx/graph.rs` (~77%): some graph traversal helpers remain
  uncovered — candidate for a future coverage pass.

Six more items closed (all 3 Tiers except T3.7, which stays in baseline):

  `Box<dyn AudioBackendTrait>`; `update_sources` orchestration, spatial

  `extract_material` branch (all OpenPBR parameter groups), the `color4`
  base_color path, and a surface-without-output graph.

  `for_each_entity!`); T2.3 done — Pack is integrated, not dead code
  (`crates/core/tests/pack_integration.rs`). trybuild error paths added for
  `for_each_entity` (non-reference arg), `kernel` (non-integer attr) and
  `gpu_pipeline` (unknown option) — the known gap from the morning is closed.
- **GPU physics / single-point NGS (T2.5)**: verified working. Single-point
  manifolds flow through `rebuild_islands` into the CPU `solve_contacts_position`
  (NGS) pass; `gpu_solver_tracks_cpu_engine` (feature `gpu`) asserts the GPU
  and CPU paths settle to the same resting state (< 5 cm). No code change
  needed — the item was already satisfied.

  round over `physics`/`render`, not a test-coverage task.
